# WeChurch B：跨年齡操作體驗檢視

## 範圍與成功條件

沿用既有品牌、網址、登入、權限與資料。A 站不變。不增加導覽層級，不以教學面板彌補不直覺的操作。

成功條件：核心入口名稱一致；管理者可依工作找到工具；筆記能用觸控、滑鼠與鍵盤明確展開且閱讀時不誤收合；空狀態可直接開始；標準與最大字級在手機與桌面不溢出；權限與分享確認不退化。

## 程式碼審查發現

| 問題 | 影響 | 本輪修正 |
| --- | --- | --- |
| 後台把會員、寄信、題庫、系統開關並列；管理後台標題重複 | 同工難以分辨日常工作與系統管理 | 依會友與牧養、靈修與通知、工具與設定分組，保留所有既有入口和權限條件 |
| CRM、框架、個人/門訓、代求等名稱不一致或不明確 | 新使用者需要猜測功能 | 改用會員與牧養、牧養階段、門訓跟進、代禱關懷等直白名稱 |
| 筆記靠點整張卡片展開；內容被點擊也會收合 | 鍵盤使用者缺乏明確控制；選字閱讀容易誤操作 | 明確展開／收合按鈕，ARIA 狀態，閱讀內容不再觸發收合 |
| 我的筆記、查看筆記、經文感動；個人管理、個人設定混用 | 同一功能像不同功能 | 統一我的筆記、靈修筆記、個人設定、讀經計畫 |
| 筆記空狀態只有操作說明，沒有直接開始按鈕 | 首次使用停在空頁 | 提供開始今日靈修入口 |
| 部分後台純圖示沒有可讀名稱，回首頁含巢狀互動元素 | 螢幕閱讀器與鍵盤操作不明確 | 命名、單一連結、可見返回文字、載入狀態 |
| 會員管理頁頂部工具很多，未納入前輪最大字級驗收 | 手機／大字可能擠壓標題 | 允許工具列換行，新增驗收覆蓋 |
| 手機選單開啟後，點頁面標題回首頁不會收起選單 | 到了新頁卻被舊選單遮住，像沒有切換成功 | 重現失敗測試後，補上標題點擊和頁面切換時收合 |
| 320px 最大字級的管理項目選單超出可見區，選項無法點擊 | 後台功能實際無法切換 | 下拉選單依可用視窗高度限制尺寸、保留內部捲動，選項提供足夠操作區 |
| CRM 純圖示按鈕跟著文字變成近 100px，篩選欄又固定 140px | 大字模式反而難操作、標籤遭截斷 | 圖示保持 44px，篩選欄隨文字需要展寬 |
| 最大字級會員卡片的操作按鈕擠壓姓名，分頁列超出手機寬度 | 名稱無法辨識，需要橫向捲動 | 操作按鈕固定在卡片上角，姓名與郵件完整換行；分頁列可換行；特大與最大字級會員分類改兩欄 |
| 窄手機的後台兩欄工具把中文字切成短碎行 | 名稱不易掃讀 | 480px 以下改單欄工具入口，保留圖示與完整文字 |
| 平板最大字級的會員摘要與表格仍維持密集欄位 | 可捲動但文字成窄直欄，難以閱讀 | 特大／最大字級依內容寬度排摘要，會員清單切為卡片；跟隨閱讀偏好即時切換 |

## 檢視地圖與保留事項

- 每日入口：首頁、聖經入口、每日靈修、研經、讀經計畫、我的筆記。保留閱讀位置、私人草稿、儲存失敗訊息與分享預覽。
- 互動：禱告／恩典記錄簿、禱告牆、靈修牆、小家。保留匿名、選擇分享範圍、未加入小家的申請／邀請入口，不能默認公開。
- 個人：個人設定、待回應、我的分享、關懷、陪伴／門訓。保留撤回、封存確認、資料範圍與無權限狀態。
- 管理：管理入口、會員牧養、角色權限、每日靈修課表、通知寄信與收件匣。保留按職分授權、匯入預覽、發佈確認及寄信保護。
- 次要工具：破冰、分組、問答、話語卡、耶穌時間軸、愛的旅程。路由仍保留；本輪不擴大首頁入口，也不重新開啟收斂功能。
- 登入、重設密碼、404、錯誤／載入／無資料狀態：不得把錯誤誤報為沒有資料。

## 驗收界線

修改前 B 站基線：22 個檢查通過，無橫向溢出或前端例外，但手機會員管理標題遭截成「教…」；後台工具並列、重複標題與筆記隱藏操作仍存在。這也說明版面不溢出不等於容易使用。基線截圖：`output/playwright/reading/365954c2-7be9-46b2-b84b-b4d12ad0380e/`。暫時測試帳號已刪除，A 部署未變。

### 元件與視覺規則

- App shell：Header、MobileNavigation、AppLayout、ReadingScrollRestoration。保留五大導覽、單層手機頂欄與原有返回邏輯。
- 按鈕、分頁、選單、警告對話框：沿用 Radix/shadcn 與 Lucide，保留既有 data-testid；新展開按鈕有 aria-expanded／aria-controls。純圖示需可讀名稱，避免連結裡再放按鈕。
- 字級：沿用五級全站文字與兩種閱讀字型；正文行距 1.85，手機內容邊距 16px，最大字級以換行而非縮小文字處理。
- 顏色：沿用明暗主題的 background/card/foreground/primary/border tokens，不換品牌。後台移除獨立漸層橫條，與其他工作頁使用相同主題色。
- 後台以工作分區、可掃讀標題及工具列為主，不增加行銷式大標、說明卡片或新導覽層級。

### 優先次序

1. 本輪交付：一致命名、後台工作分組、明確可操作的筆記、手機標題與大字排版，保留所有資料和權限。
2. 真人驗收：至少年長／一般會友、同工各一人，不先教操作；記錄完成任務時間、走錯入口、需要協助及文字選擇。
3. 後續再依證據調整：進階牧養、匯入、寄信、多人小家互動與次要工具。不要因本輪截圖通過就宣稱整站每種情境都易用。

### 參考準則

文字放大應避免內容和功能遺失，除最大字級也要留意中間各級，參考 [W3C Resize Text](https://www.w3.org/WAI/WCAG22/Understanding/resize-text.html)。按鈕除了尺寸，也要考慮間距和誤觸，參考 [W3C Target Size Minimum](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)。本專案主要按鈕使用至少 44px 操作區，是本輪工程選擇，不代表所有畫面已符合 WCAG 認證。

程式碼檢視不等於每個功能完成實測。發布後另記錄實際 B 站路由、角色、操作、視窗、字級與截圖。用隔離測試帳號；不寄真信、不分享私人內容、不異動真實會友資料。

實體 iPhone／Android、年長會友首次操作、所有個別小家與特定會員詳細資料、各種實際匯入檔與郵件送達，不以自動化截圖代替驗收。建議真人驗收任務：找到今日靈修、寫下並儲存私人筆記、找到小家、調整文字大小；同工另測找到會友、安排探訪、找到權限設定。
