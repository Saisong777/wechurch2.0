# 小家一起讀經：字級、私人原稿與選欄分享

Task key: `wechurch-group-reading-workflow-20261016`。此實作沿用 Handshake A
與現役小家功能；Primary Owner 為 WeChurch。canonical task helper 對活動來源
未接入，沒有另造 UUID 或宣稱正式任務登記完成。

## 閱讀與寫作

- 字級沿用 `wechurch-devotion-font-size`，範圍 16–26、預設 20。只有
  `church-reader` 經文、靈修、回應禱告及愛人行動套用閱讀字級，控制項與
  整個頁面不放大；沿用原來的經文展開狀態。
- 「分享這一天的領受」打開同欄位的 inline 編輯器，先載入當天經文的私人
  看見／領受／回應。載入失敗先顯示重試，不開空白表單覆蓋原稿。
- 每欄分別勾選分享；至少一欄非空，才可預覽。預覽只顯示勾選欄，送出還需
  對具名小家明確同意。修改內容／分享選擇／已讀選擇會收起預覽、重置同意。
- 「儲存筆記並分享至小家」只發一個結構化原子請求，包含完整私人三欄與
  `shareFields`；不由瀏覽器組裝或傳送公開 `body`。完整私人原稿及分享快照
  由 server 同一交易保存，不能把分段成功當整體成功。
- 「同時標記已讀完這天進度」預設勾選且可取消。原本單獨「與小家分享已讀」
  保留；回看私人筆記入口仍在。此新流程不是新的純私人儲存 API。

## 草稿與復原

私人載入 query key 包含 owner、church scope、group、date；session 草稿還包含
devotion ID。切換日期／小家／教會／帳號時不顯示別個範圍的原稿或草稿。回到
相同範圍後重新開啟可續寫；收起不送出、不丟棄草稿。

送出期間禁止重複確認。失敗保留原 immutable request 及 mutation ID，不自動
重送；明確「重新確認原送出結果」只重送同一筆內容。離開範圍後才到達的結果
不關閉另一份編輯器、不清除原草稿，回原範圍可用同一 ID 查明結果。

確定的 400／401／403／404／409／413／422／428 拒絕與傳輸中斷／5xx 結果
未知分開處理。前者保留草稿並提供明確重新載入、比對與新預覽的恢復入口，
不讓表單永久卡在同 UUID 重試；後者先確認原請求，避免重複分享。被鎖定的
原請求三欄使用唯讀文字框，仍可選取複製。若重新載入私人筆記遭 403／404，
顯示此範圍已保存草稿的可複製唯讀版本與回看私人筆記入口，沒有送出按鈕；
不繞過權限，也不自動建立或復活筆記。收起重開仍保留這些草稿與拒絕狀態。

409 或已知版本差異先重載版本，保留草稿並列出目前 server 私人原稿。使用者
先比對整理，明確勾選確認後才能新預覽；重載後尚未比對的狀態會隨草稿保存，
收起重開不會略過。新送出重新選用 mutation ID、重新確認小家同意。這不會
默默合併、覆蓋或自動重送其他裝置的新筆記。

## 回看與保留流程

當天讀經下方顯示 `shares?kind=note&date=...`，只用 server 回傳的未撤回資料。
「回看小家領受」進現有小家動態「亮光」，沿用完整歷史分頁，不加日期過濾；
舊未關聯日期分享仍在完整歷史。既有編輯、撤回、留言、分享私人來源、代禱及
生活流程保留。預讀明天仍不提供日課筆記／分享／打卡操作。

## 驗證範圍

程式測試覆蓋原有入口、預讀與午夜、字級偏好、當天列表／完整歷史分頁、獨立
打卡、三欄載入、只選一欄預覽、取消與範圍隔離、重複送出、失敗同 ID 重試、
跨教會遲到結果、明確 4xx 拒絕後恢復、權限失敗後草稿複製及版本衝突後原稿
比對。標題與預覽接焦點，不自動聚焦輸入框；
保留 44px 控制項與無新增動態效果。
