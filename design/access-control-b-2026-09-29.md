# 角色與權限管理：B 站

## 範圍

入口 `/admin/access`，由管理後台及會員選單进入。只發布 B，不更動 A 或現有會員的實際授權。

- 預設職分：主任牧師、牧者、同工、小家長、長老、執事、會友；可新增名稱。
- 同一會員可以兼任多個職分。職分名稱本身不提供管理權。
- 功能勾選：會員名單、會員編修、小家管理、門訓階段與跟進任務、牧者探訪、寄信、靈修課表、公開分享管理。
- 範圍：教會、小家、指定會員。探訪限教會；小家管理不能選單一會員。
- 靈修課表及公开分享目前是全站公共模組，須系統管理員使用「全站公共內容」範圍授權，不偽裝成多教會隔離。
- 到期、撤回、本人或目標轉教會、小家失效，下一次請求重新判斷。

## 授權來源與隱私

這是漸進式整合，不一次替換所有既有角色。有效權限是既有帳號角色、舊 CRM scope、小家任命、新增授權的聯集；畫面列出各來源，撤回其中一筆不等於撤回全部。

新增職分範本都是空權限。範本只在授權時明確套用；修改範本不連動既有授權。修改會員原有帳號角色另外確認、稽核，最後一位系統管理員不可降級。

勾選不開放個人未分享的筆記／禱告。小家管理不等於加入小家，不能讀取未獲分享的組內內容；私人陪伴收件匣仍遵循本人指定收件者的原有規則。牧養概況與出席仍依既有小家任命／CRM scope，未加入新的出席權限勾選。

撤回公开貼文只撤回公开副本，保留個人原稿。寄信仍受收件範圍、訂閱／退訂、寄信政策及重複送信保護限制，不會因授權跳過這些檢查。

## 工程與驗收

- Migration `0021_access_control`：職分範本、授權、稽核三表；不變更會員原角色，不修改個人內容。
- 寫入含角色檢查、嚴格欄位驗證、範圍檢查、跨站寫入阻擋、交易內稽核；編輯／撤回使用版本檢查，新建採可重試收據識別碼。
- 帳號角色變更共用序列化交易保護，涵蓋新頁及原會員頁。
- 隔離 PostgreSQL + 真實 HTTP 測試涵蓋多職分、跨教會、自我提權、只讀／編修分離、模板不連動、到期／轉教會／撤回、私人原稿、小家管理與私密內容分離、探訪安排及最後管理員保護。
- 前端測試涵蓋明確套用範本、範圍重選清除權限、確認取消、儲存失敗保留輸入。
- `ops/verify-access-staging.mjs` 使用獨立合成會員執行 B 站授權與撤回、中文稽核、320／390／1440px、深色及清理讀回。不寄信、不替真實會員加權。
