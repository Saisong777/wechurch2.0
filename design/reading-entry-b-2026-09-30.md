# B 站讀經入口簡化

## 目標與範圍

使用者指出聖經入口只有三張卡片，操作多了一層。改為主導覽直接開啟聖經，閱讀頁提供「讀聖經／每日靈修／我的筆記」連結，省去中間入口頁。不變更讀經資料、會員、筆記、分享權限、譯本、收藏或登入方式；A 站不發布。

## 實作

- `/learn` 以 replace 導向 `/learn/bible`，保留 query/hash；聖經功能關閉時改進每日靈修，父功能維護及載入失敗仍受 FeatureGate 保護。
- 三個閱讀頁及舊 `/bible` 路徑使用同一切換列，標記當前頁；點當前聖經分頁不清除章節參數。
- 聖經頁直接開啟時，返回備援改為首頁，避免經過已移除的入口再次回到聖經。
- 切換列不是固定／浮動工具列。手機隱藏裝飾圖示、保留文字；點擊區至少 48px，文字可換行。
- 第一輪大字驗收發現 rem 留白放大造成四行直排；已改為固定間距，保留字體放大，最窄 320px／最大 36px 字級為兩行。

## 驗收證據

- 130 個測試檔、728 項功能測試及 36 項部署測試通過；型別、正式建置與隔離 DB 真實 HTTP 權限測試通過，測試 DB 已移除並核對。
- 本次新增／直接修改檔案的定向 lint 無錯誤；不宣稱全專案零警告。
- B 實際 `/learn` 自動進聖經；已登入 Chrome 的 `/learn?book=43&chapter=3#v16` 保留參數並顯示約翰福音第三章。
- 已登入 Chrome 實際完成聖經 → 我的筆記 → 每日靈修 → 聖經；筆記的讀經計畫／靈修筆記頁籤正常，切換列正確標記當前頁。未編輯任何筆記。
- 未登入進入我的筆記時導向登入；B 專用 Google、邀請保護、PKCE/state、偽造／取消回呼拒絕及帳號數不變檢查通過。未重新進行真人 Google 同意流程。
- 瀏覽器桌面 1440px、手機 320px 標準／最大字體與明暗畫面已核對。最終 320px 標準字級切換區高 50.75px、最大字級 125px，各連結無內容溢出，頁面 scrollWidth 等於 viewport 320px。
- 驗收範圍是本次入口／切換列，不代表整個研經工具在所有極端字級下的全面驗收；實體 iPhone／Android 未在本輪重測。
